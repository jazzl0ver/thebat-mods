# The Bat! mods

Модифицированный `TheBat64.exe` со следующими изменениями:

- история автодополнения адресов: **40 → 1000**
- восстановлена старая иконка The Bat! для Explorer / taskbar / tray
- высота строк списка писем: **16 → 20 px** — ближе к виду The Bat! 9.5 с `Row density`

## Установка

1. Закройте The Bat!
2. Сохраните оригинальный `TheBat64.exe`
3. Замените его модифицированным файлом
4. Запустите The Bat!

> После модификации оригинальная цифровая подпись EXE недействительна.
